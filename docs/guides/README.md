## Скрины

Лежат в `img/` и снимаются скриптом `shoot.mjs` с локального приложения: тёмная тема, русский язык, окно 1440×900, демо-аккаунт без личных данных.

```bash
GUIDE_SESSION=<токен fw_session демо-аккаунта> node docs/guides/shoot.mjs
```

Без аргументов снимаются все сцены, иначе только перечисленные, например `node docs/guides/shoot.mjs snipes-home idea-chat`. Нужны запущенные фронт (`GUIDE_URL`, по умолчанию `http://localhost:3002`) и бэкенд. Сцены `ai-filter`, `ask-answer`, `ideas-*` и `idea-chat` при первом прогоне обращаются к ИИ и тратят кредиты демо-аккаунта; потом берут сохранённое.

Сцены и файлы: `snipes-home`, `snipes-cards`, `snipes-settings`, `snipes-settings-ai`, `ai-filter-prompt`, `ai-filter`, `ask-question`, `ask-answer`, `ideas-taste`, `ideas-studio`, `ideas-card`, `idea-chat`.
